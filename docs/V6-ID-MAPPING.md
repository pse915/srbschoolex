# v6 맵 id · 좌표 매핑 표

v6에서 학교 교정·1~4층을 실제 교실배치도 기준 ┌자로 다시 만들면서 바뀐 맵 id와 좌표입니다.
방 id는 **이름이 같은 실은 기존 id를 그대로 유지**했습니다(교실 1-1~3-6 포함). 그래서 스토리(`story_v4.json`의 `room-2-1` = 1학년 2반)와
게임 코드(`travel()`의 `room-2-1`)는 고칠 필요가 없었습니다. 실 이름·위치의 원본은 `data/school_layout.json`입니다.
