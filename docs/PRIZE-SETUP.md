# 79곳 완료 상품 — 학번·이름을 GitHub에 기록하기 (선생님용)

학생이 장소 79곳을 모두 탐방하면 학번·이름을 적는 창이 뜹니다.
저장하면 GitHub 저장소에 기록되고, 화면에 **"2층 교무실 선생님에게 찾아가세요."** 가 나옵니다.
그다음 기기의 장소 카드는 0으로 돌아가 다음 학생이 처음부터 시작합니다(카드는 그 전까지 기기에 계속 쌓입니다).

## 1. 기록용 비공개 저장소 만들기 (처음 한 번)
1. GitHub에서 **New repository**를 누릅니다.
2. 이름은 예를 들어 `srbschoolex-records`로 하고, 반드시 **Private**를 고릅니다.
   - 학생 이름이 들어가므로 게임 저장소(`srbschoolex`, 공개)에 기록하면 안 됩니다.
3. **Add a README file**을 체크하고 만듭니다. 빈 저장소에는 기록을 쓸 수 없습니다.

## 2. 열쇠(토큰) 만들기
1. GitHub 오른쪽 위 프로필 → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**을 엽니다.
2. 아래처럼 고릅니다.
   - **Repository access:** Only select repositories → `srbschoolex-records` **하나만**
   - **Permissions → Repository permissions → Contents:** Read and write (다른 권한은 주지 않음)
   - **Expiration:** 학기 끝 정도로 짧게
3. 만들어진 열쇠(`github_pat_…`)를 복사합니다. 이 화면을 닫으면 다시 볼 수 없습니다.

> 열쇠를 게임 코드(공개 저장소)에 넣지 마세요. GitHub가 공개된 열쇠를 찾아내 바로 폐기합니다.
> 열쇠는 아래처럼 **사이니지 기기에서만** 입력합니다.

## 3. 사이니지(플립2)에 입력하기
1. 플립2 브라우저 주소창에 `https://pse915.github.io/srbschoolex/?setup` 을 엽니다.
2. **선생님 설정** 창에 넣습니다.
   - 저장소: `pse915/srbschoolex-records`
   - 열쇠: 복사한 토큰
   - PIN(선택): 숫자를 넣으면 다음부터 이 설정 화면을 열 때 PIN을 물어봅니다.
3. **저장** → **연결 시험**을 누릅니다. "연결됐어요"가 나오면 끝입니다.
4. 주소를 `https://pse915.github.io/srbschoolex/` 로 되돌려 둡니다.

열쇠는 그 기기의 브라우저 저장소(localStorage)에만 남고, 화면에 다시 보이지 않습니다.
브라우저 기록·사이트 데이터를 지우면 열쇠도 지워지니 3번을 다시 하면 됩니다.

## 4. 기록 보기
- 저장소의 `records/날짜/시각-학번.json` 파일 하나가 학생 한 명입니다(학번, 이름, 완료 시각, 장소 수).
- 인터넷이 끊겼을 때도 학생에게는 안내가 나오고, 기록은 기기에 보관했다가 연결되면 자동으로 보냅니다(시작 후 4초, 그 뒤 5분마다).
- `?setup` 화면에서 이 기기의 최근 완료 기록 20건과 보내지 못한 기록 수를 볼 수 있고, **보관 기록 다시 보내기**로 바로 보낼 수 있습니다.

## 5. 알아 둘 점
- 열쇠는 그 기기 안에만 있지만, 기기를 직접 만질 수 있는 사람이 브라우저 개발 도구를 열면 꺼낼 수 있습니다. 그래서 열쇠는 기록 저장소 하나, Contents 권한 하나만 주고 기간을 짧게 잡으세요.
- 열쇠가 새었다고 생각되면 GitHub 토큰 화면에서 그 토큰을 **Delete**하고 새로 만들어 3번을 다시 하면 됩니다.
- 카드는 기기에 계속 쌓이므로, 앞 학생이 모은 카드를 다음 학생이 이어서 채울 수 있습니다. 상품을 줄 때 확인해 주세요.
