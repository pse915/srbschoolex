# v6 보고서 — 학교 외관(코드 픽셀아트) + 교정·층 맵 ┌자 재구성

작업 브랜치: `v6-lshape` · 기준 문서: `docs/kiosk/00_서라벌여중_배치_기준표.md`, `docs/kiosk/01_학교외관_픽셀아트_재제작_프롬프트.md`
중앙현관 위치는 스크립트 원래 값(XE = D+38 = 56m)을 그대로 썼습니다(사용자 결정).

## 2. 그림체 규칙 확인

- `python tools/school_art.py --out components/rpg_game/assets --only all` 이 오류 없이 끝남(약 2초).
- 두 번 실행한 결과 파일 19개의 SHA-256이 모두 같음. 커밋된 에셋과도 같음(`tests/test_school_layout.py`가 매번 검사).
- `school.png`·`school-hero.png`는 art-v1 기준 이미지와 픽셀 차이 0.
- 색은 스크립트 상단 팔레트 상수만 씀. 새 색은 상수로 추가: CRACK, SHARD, STAIN, SAND*, LINE, PAVE*, PLAN_*.
- 확대는 항상 정수 배율 + nearest. 게임에서는 2배(1712×688). 시계탑·커튼월·글자 없음.
- 기하 상수 추가: `MSTAIR`, `ESTAIR_W`, `OUTER_W`, `CORR_W`, `EV_X`, 그리고 site 상수(FIELD, ANNEX, GATE_E/N, FOUNTAIN). 외관 그림, 평면도, 게임 맵, kiosk-plan이 모두 이 값에서 나오므로 값을 바꾸면 함께 바뀝니다.

## 3. `data/school_layout.json` 형식

```json
{"floors":[{"floor":1,
  "west":{"inner":[{"id":"room-1-6","name":"행정자료실","category":"service"}, {"anchor":"westMidStair"}, ...],
          "outer":[{"id":"room-1-15","name":"화장실","category":"restroom","anchor":"westWC"}, {"gap":1}]},
  "main":{"inner":[..., {"id":"lobby-1","name":"중앙현관","kind":"lobby","anchor":"lobby"}, ...],
          "outer":[{"gap":1}, {"anchor":"ev"}, ..., {"anchor":"centralStair"}, ...]}}],
 "outdoor":[{"id":"place-annex","name":"목련관","site":"annex","aliases":["급식실","강당"]}, ...]}
```
- **순서:** 서쪽 동은 꺾임부 → 남쪽 끝, 본관은 꺾임부 → 동쪽 끝(기준표 2장).
- **`anchor` 칸:** 계단, EV, 로비, 교직원화장실 자리처럼 모든 층에서 같은 미터 좌표에 고정됩니다. 나머지 실은 고정 칸 사이를 `span` 비율로 나눕니다.
- **`gap`:** 배치도에 "…"로만 표시된 칸입니다. 이름을 지어내지 않고 벽(빈 칸)으로 둡니다.
- **교사가 고치는 칸:** `name`, `aliases`, `name_en`, `description`, `visible`, `game`, `confirmed`.
- **`id`:** 맵 이름이므로 바꾸지 않습니다.

## 4. 교정 맵 설계 (school.json)

```
 x→ 30        45   50        64            90       110   127
 22 ·······························[후문]·························
 40 ·           ▓▓▓▓▓▓▓▓▓▓▓▓▓▓ 본관 (지붕·벽, 2배 스프라이트) ▓▓▓▓
 46 ·          ▓▓▓■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■■ ← 발자국(solid)
 50 ·        ▓▓■■ 화단 ░░ [현관 64,50] [조회대] 화단 ░░ ════ 보도블럭 ═══ [정문]→미래마을
 52 ·       ▓▓■■  급수대    ●스폰 64,52                     ║
 56 ·     ▓▓■■     ┌─────── 운동장(모래·트랙) ───────┐       ║
 62 ·   ■■■■ ← 서쪽 동(경사 투영)                     │   [목련관]
 70 ·            └───────────────────────────────┘
```
- **스프라이트 위치:** 현관 바닥점(XE, D)이 타일 (64.5, 50)에 오도록 놓았습니다. 그래서 스폰 [64,52], 기술썜 (62,51), 다이어리 (64,51)이 v5와 같습니다.
- **solid 타일:** footprint의 ┌ 다각형을 타일 중심점으로 역투영해 계산했습니다. 화단·소나무·현관 기둥 2개·급수대·목련관·정문/후문 담장도 solid입니다. 현관 계단과 조회대는 걸을 수 있습니다(조회대 = 올라가는 오브젝트).
- **그리기 순서:** 오브젝트에 `sortY`(정렬 기준 행)와 `ground`(바닥 레이어) 속성을 추가했습니다.
  - 건물은 본관 남쪽 면 줄에서 정렬하므로, 현관 앞 캐릭터의 머리가 벽에 가려지지 않습니다.
  - 운동장 바닥은 항상 맨 아래에 그립니다.
- **landmarks:** crisis.js·ending_visual.js가 쓰던 하드코딩 좌표(셔터, 배움·돌봄 공간, 옥상 정원, 학생 위치, 외벽 창 위치)를 `school.landmarks`·`endingView`로 옮겼습니다.
- **미니맵 색:** `minimapColors`로 건물 발자국을 벽돌색으로 칠해 ┌자가 보이게 했습니다.

```
 4 ┌──────┬────────────────────────────────────────────┐
   │ 빈칸   │ EV  회의실…  [중앙계단][교직원WC] 탈의실 …  WC/준비실 │ y 4–10 (바깥, 북)
11 │   ┌──┴────────────────────────────────────────────┤
   │   │ 본관 복도 ════════════════════════════════════════ │ y 11–13
14 │   │  ┌[꺾임계단]┬ 실 … ┬[로비/실]┬ 실 … ┬[계단]┬ 실 ┬[계단]┤ y 14–21 (안쪽, 남)
22 ├WC─┤  ├─────────┴─────┴────────┴──────┴─────┴────┴─────┘
   │바깥│║│안쪽 실  서쪽 동: 바깥(서) x 4–10 / 복도 x 11–13 / 안쪽(동) x 14–21
47 │   │║│[계단]   STAIR_Y0..Y1 (D+25..30)
   │   │║│안쪽 실  ← 4층은 여기서 막힘(아치 지붕 구역, confirmed:false)
78 └───┴─┴──────
```
- **문:** 각 실 문 포털은 복도에서 실 쪽 가장자리 칸에 두고 `room-층-번호` 맵으로 연결했습니다. 실 쪽에는 문 타일을, 본관 바깥쪽 실에는 문 그림을 놓았습니다.
- **층 이동:** 계단은 위아래 층, EV는 모든 층으로 이동합니다(포털 42개).
- **스폰과 출입구:**
  - 1층 스폰은 로비(사이니지 자리 근처)입니다. 로비 남쪽 '교정으로' 포털은 교정 현관 앞으로 나갑니다.
  - 2~4층 스폰은 중앙계단 앞입니다.

## 8. 남은 불확실 사항 (확인 필요)

1. **4층 서쪽 동 끝(아치 지붕) 구역:** 배치도에 표기가 없어 "4층 없음"으로 추정했고 `confirmed:false`입니다. 실제로 4층이 있으면 `data/school_layout.json`의 `void-4-west` 항목을 실 목록으로 바꾸고 다시 생성하면 됩니다.
2. **1층 현관 동쪽 실이 좁음:** 중앙현관을 XE=56에 두었기 때문에, 현관과 동쪽 중간 계단 사이 11.5m에 실 4개가 들어갑니다. 방송실·교육공무직원실·과학교과연구실은 각 2.3m입니다. 배치도 비율(XE≈47)과 다르니, 바꾸려면 `XE` 상수 하나만 고치면 됩니다.
3. **1층 본관 동쪽 끝:** 기준표 1장은 "각 층 동쪽 끝 화장실"이라고 하지만, 1층 표와 배치도는 그 자리를 `과학준비실`로 적고 있습니다. 1층 표를 따랐고, 1층에는 동쪽 끝 화장실을 두지 않았습니다.
4. **이름 없는 바깥쪽 칸:** 배치도에 "…"로만 있는 바깥쪽 지원공간(꺾임부 북서쪽, 서쪽 동 바깥쪽, 본관 동쪽 바깥쪽 일부)은 이름 없이 벽으로 두었습니다.
5. **치수:** 건물 깊이 18m, 본관 104m, 서쪽 동 56m, 층고 3.6m, EV·계단 폭은 추정치입니다. 목련관·정문·후문·급수대의 위치와 크기도 배치도 비율을 보고 정한 값입니다.
6. **교정 미니맵·바닥이 비스듬함:** 게임 시점 투영(X = x − 0.5y)이 고정이라, 교정 지도에서 서쪽 동은 왼쪽 아래로 비스듬한 ┌로 보입니다(층 맵은 똑바른 ┌). 교정 맵 아래쪽 절반은 나무만 있는 빈 땅입니다.
7. **기존 동작:** 층 이동 알림이 "서라벌여중 · 2층 · 2층"처럼 층이 두 번 나옵니다. v5부터 있던 표시이고 이번에 고치지 않았습니다.
