# 서라벌 탐방 (새 게임) + 학교 전체 지도 — 보고서

기준 프롬프트: `docs/kiosk/03_서라벌_탐방게임_새로만들기_프롬프트.md` · 브랜치 `explore-v1`
기존 생애설계 게임(`components/rpg_game`)은 그대로 두고, 그림과 학교 배치 데이터만 가져와 새 게임을 따로 만들었습니다.

## 1. 무엇을 만들었나

| 구분 | 내용 |
|---|---|
| 새 게임 | `components/explore/` — 독립 정적 웹앱. Canvas 2D, 빌드 도구·외부 CDN 없이 동작. 기존 게임 코드는 import하지 않고 새로 작성 |
| 학교 전체 지도 | 게임 안 [지도] 버튼(M 키) + 단독 화면(`?map`, Streamlit "학교 전체 지도") |
| 데이터 생성 | `tools/build_explore_data.py`: school_layout.json + kiosk-plan.json + school-footprint.json + 맵 JSON → `components/explore/data/places.json`, `data/maps/*.json`(85개), `assets/`(그림 24장 사본 + sha256) |
| 새 그림 | `tools/school_art.py --only explore`: 입체 지도 층판 `stack-floor-1~4.png`, 지도 핀 `map-pin.png`, 스탬프 `stamp.png`. 같은 팔레트로 그렸고, 기존 출력 해시는 변하지 않음 |
| Streamlit | `app.py` 사이드바: **학교 탐방 게임(새)**(기본) / **학교 전체 지도** / 생애설계 게임(기존) / 교사용 대시보드 |

## 2. 가져오지 않은 것
- **기존 게임 시스템:** 스토리·챕터, 퀘스트·생애 선택·퀴즈·정책 프로젝트, 위기·50년 뒤·엔딩, 다이어리
- **길 안내:** 노란 길 안내 화살표·발자국·"현재 목표" 패널
- **그 밖:** 미래 마을, 서버 저장·토큰·Google Sheets
- **기존 대사:** 맵 JSON의 npcs·interactions(생애설계 대사)와 futureLayers는 생성 단계에서 빼고, 장소 정보로 새로 만들었습니다.
- **확인 방법:** `tests/test_explore_data.py`가 새 데이터와 JS에 이 내용이 남아 있지 않은지 매번 검사합니다. 기존 대사 문장, "미래 다이어리"·"생애"·"퀴즈" 같은 단어, `story_v4`·`futureLayers`·`routeTarget` 같은 코드 이름을 찾습니다.

## 3. 게임 규칙 ("서라벌 탐방")
- **시작 화면:** 화면을 반으로 나눕니다. 왼쪽(흰색) **서라벌 탐방하기**는 누르면 게임이 시작되고, 캐릭터 6종은 그 안에서 고릅니다. 오른쪽(색이 천천히 바뀌는 초록) **서라벌여중 길 안내**는 누르면 "현관에서 가는 길"이 켜진 학교 지도가 열립니다(스크린샷 `25~28`).
- **시작:** 캐릭터 선택(이름 입력 없음) → 교정 중앙현관 앞에서 출발.
- **이동:** 교정 → 중앙현관 → 1~4층 ┌자 복도 → 각 실.
  - 문 칸을 밟으면 들어갑니다.
  - 계단·EV 칸을 밟으면 층 선택 창이 뜹니다.
- **장소 카드·도감:** 실에 들어가거나 교정 장소에 닿으면 카드를 얻습니다. 카드 내용은 이름, 층·구역, 카테고리, 소개 문장입니다.
  - 모을 수 있는 장소는 79곳(실 73 + 교정 6)입니다.
  - 교직원화장실·탈의실(game:false)과 4층 서쪽 끝 구역(confirmed:false)은 뺐습니다.
- **찾아가기 미션:** 층·구역이 섞이게 3곳을 뽑아 이름과 층만 보여 줍니다. 화살표는 없습니다.
  - 제한 시간 3분은 메뉴에서 켜고 끌 수 있습니다.
  - 결과 카드에 걸린 시간과 칭호(번개 탐험가, 4층 마스터, 서쪽 동 탐험가, 교정 산책가, 서라벌 탐험가)가 나옵니다.
- **안내 사람:** 층마다 3~5명, 교정에 3명이 있습니다. "여기서 가장 가까운 곳은 ○○이야" 같은 문장을 places.json에서 자동으로 만듭니다.
- **조작:**
  - 탭-이동(누른 칸까지 걸어감. 길은 표시하지 않음)
  - 방향 패드
  - 방향키/WASD, Enter(말 걸기), M(지도)
  - 여러 손가락이 동시에 닿으면 첫 터치만 씁니다.
- **미니맵:** ┌자 모양이고 내 위치만 표시합니다.
- **확대:** 캐릭터가 잘 보이도록 게임 화면을 보통 화면에서 2배, 큰 화면(1200px 이상 높이)에서 3배로 확대합니다.
- **자동 지도:** 1분 동안 아무 조작이 없으면 학교 전체 지도(교정 탭)로 넘어갑니다. 시작 화면에서도 같습니다(`game.js`의 `G.idle.ms`).
- **실내 꾸밈(학교 사진 기준, `tools/interior_art.py`):**
  - 복도(1~4층): 점박이 테라조 바닥, 흰 벽과 갈색 나무 손잡이 띠, 연두색 기둥·문틀, 나무 문(화장실은 반투명 유리문), 초록 게시판, 계단·EV 앞 노란 점자블록, EV 은색 문. 실 이름은 실제처럼 문 위 청록색 표지판으로 표시합니다.
  - 중앙현관: 큰 바닥 타일, 양옆 나무 벽, 유리 출입문 두 쌍과 가운데 시계, 사이니지 거치대, 화분, 안내 배너, "힘써 배우고 바르게 행하자" 액자.
  - 방송실: 어두운 바닥, ON AIR 등이 달린 부스 창, 부스 문, 모니터가 놓인 방송 책상, 장비 랙, 벽 패널, 연두색 의자.
  - 생성은 `tools/build_explore_data.py`가 함께 합니다(그림 `assets/interior-tiles.png`, `interior-props.png`). 스크린샷 `docs/screenshots-explore/20~24`, 확인 스크립트 `tests/interior_screens.cjs`.
- **저장:** 이 기기 localStorage에만 익명으로 저장합니다(도감, 최고 기록, 캐릭터). 메뉴에서 지울 수 있습니다.

## 4. 학교 전체 지도
- **탭:** 교정 / 1층 / 2층 / 3층 / 4층 / 입체
  - **교정:** 게임과 같은 그림을 school-footprint 좌표로 배치했습니다. 정문·후문은 화면 가장자리에 화살표 이름표로 표시합니다. **본관이나 서쪽 동 건물을 누르면 1층 지도로 바뀌고** 그 동이 테두리로 깜빡입니다.
  - **층:** `floor-plan-N.png`(글자 없음) 위에 실 이름을 캔버스 글자로 얹습니다. 좁은 칸은 두 줄로 쓰거나 번호표 + 목록으로 대신합니다.
  - **입체:** 고른 층만 진하게, 나머지는 반투명으로 보입니다.
- **검색:** 이름·별칭으로 찾습니다(예: "위클래스" → Wee클래스, "도서관" → 글빛도서관). 결과를 누르면 해당 층으로 바뀌고 그 실이 깜빡입니다.
- **장소 정보:** 이름, 카테고리, 층·구역·안쪽/바깥쪽, 소개, 양옆 실, 가까운 계단·EV(복도 거리).
- **지금 여기 핀:** 게임에서 열면 플레이어 위치, 단독 화면에서는 1층 중앙현관(사이니지 위치)입니다.
- **현관에서 가는 길(지도 화면 안 선택 기능):**
  - kiosk-plan 그래프로 경로를 계산해 점선과 단계 문장으로 보여 줍니다.
  - 좌우는 사이니지 앞에서 북쪽을 보는 사람 기준이고, 계단을 올라온 뒤에는 복도로 나선 방향 기준으로 다시 계산합니다.
  - "몇 번째 문"까지 알려 줍니다.
  - 엘리베이터 경로도 고를 수 있습니다.
  - 76개 실 모두 경로가 계산됩니다.
  - 게임 화면에는 길 안내가 나오지 않습니다.
- **확인 필요 구역:** 4층 서쪽 끝은 회색 빗금과 "확인 필요"로 표시합니다.

## 6. 남은 사항 · 확인 필요
1. **장소 소개 문장:** `data/school_layout.json`의 `description`이 비어 있어서 카테고리별 기본 문장이 나옵니다. 학교에 맞는 소개를 채우고 `python tools/build_explore_data.py`를 실행하면 카드와 지도에 반영됩니다.
2. **4층 서쪽 끝(아치 지붕) 구역:** 계속 `confirmed:false`입니다. 확인되면 school_layout.json을 고치고 school_art → build_world → build_explore_data 순서로 다시 만듭니다.
3. **폰트:** 저장소에 폰트 파일이 없어 시스템 한글 폰트(맑은 고딕 등)를 씁니다. 사이니지 기기에서 폰트가 다르면 글자 폭이 조금 달라질 수 있습니다.
4. **실 안 모습:** 기존 실내 맵(가구 배치)을 그대로 씁니다. 같은 종류의 실은 비슷하게 생겼습니다.
5. **실기기 확인:** 플립2 실기기, 4K, 세로 화면, 6시간 연속 실행은 확인하지 않았습니다(02 사이니지 작업 범위).
6. **02(사이니지)와의 관계:** `components/explore`의 지도 모듈(`js/mapview.js`, `?map`)과 게임을 02에서 그대로 쓸 수 있습니다. 02를 진행할 때 "탐방 게임과 위치 안내는 components/explore를 쓴다"고 덧붙이세요.

## 7. 다시 만들기
```bash
python tools/school_art.py --out components/rpg_game/assets --only all
python build_world.py
python tools/build_explore_data.py
python tools/asset_manifest.py
python -X utf8 -m unittest discover -s tests -p "test_*.py"
npm test
```
로컬 확인: `python -m http.server 8766 --directory components/explore` 후 http://localhost:8766 (지도만: `/?map`).
