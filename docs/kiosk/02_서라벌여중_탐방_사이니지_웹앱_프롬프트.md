# 2. 구조·배포 원칙
- 기존 Streamlit 게임(app.py, components/rpg_game)은 깨뜨리지 않는다. 새 폴더 kiosk/ 에 독립 정적 앱으로 만든다.
- 엔진 코드와 에셋(타일·아바타·NPC·school.png·school-hero.png·floor-plan 등)은 복사하지 말고 상대경로로 재사용하거나,
  필요한 부분만 kiosk/engine/ 으로 얇게 분리해 기존 게임과 함께 쓰게 한다. 어떤 방식이 안전한지 먼저 제안해라.
- 서버·로그인·Google Sheets·개인정보 수집 없음. 순수 HTML/CSS/JS(빌드 없이 동작), Canvas 2D.
- GitHub Pages 로 배포(.github/workflows/pages.yml). 배포 결과물(_site)에 kiosk/ 와 그것이 참조하는
  components/rpg_game/assets·data 파일이 상대경로 그대로 들어가게 하고, 배포 전 kiosk 데이터 생성 스크립트를 실행한다.
  사이니지 브라우저 시작 페이지에 URL(…/kiosk/) 만 넣으면 되게.
- 오프라인 내성: 한 번 열린 뒤 네트워크가 끊겨도 계속 동작(Service Worker 캐시, 미지원 브라우저면 조용히 생략).

# 3. 대상 기기 제약 (플립2)
- 55인치 터치, 기본 가로(필요시 세로 회전 지원). 1920×1080 과 3840×2160 모두에서 선명하게(정수 배율 픽셀아트, image-rendering: pixelated).
- 내장 브라우저가 최신 Chrome보다 오래됐을 수 있다고 가정: 최신 문법·API에 기대지 말고, 기능 감지 후 대체 경로를 둔다.
  WebGL·모듈 번들러·외부 CDN 의존 금지, 폰트는 로컬 포함.
- 키보드·마우스 호버·우클릭·롱프레스·핀치 없음. 텍스트 선택/컨텍스트 메뉴/더블탭 확대/당김 새로고침 방지.
- 터치 대상은 최소 1080p 기준 96px 이상, 글자는 3~4m 떨어져도 읽히게 크게. 화면 아래쪽 1/3 안에 주요 버튼 배치(학생 키 고려).
- 여러 손가락이 동시에 닿아도 오작동하지 않게(첫 터치만 사용).
- 소리는 기본 꺼짐. 게임 모드에서만 작은 효과음 켜기 옵션.
- 장시간(하루 종일) 켜 둬도 메모리 누수·프레임 저하 없게. 6시간 연속 실행 테스트 기준.

# 4. 시간표 기반 모드 전환
- kiosk/config/schedule.json 에서 요일별 '게임 허용 시간대'를 정의한다. 예시 초기값:
  월~금 09:45-09:55, 10:40-10:50, 11:35-11:45, 12:30-13:30(점심), 14:15-14:25, 15:10-15:20
  주말·방학·특정 날짜(시험일 등) 게임 끄기 목록도 지원.
- 기기 시계 기준으로 30초마다 확인. 게임 시간대가 끝나기 1분 전부터 "곧 쉬는시간이 끝나요" 카운트다운,
  끝나면 진행 중 게임을 결과 화면으로 마무리하고 5초 뒤 안내 모드로 전환.
- 안내 모드에서 학생이 게임을 누르면 "다음 쉬는시간 ○○:○○에 열려요"라고 안내.
- 관리자 메뉴: 화면 왼쪽 위 모서리를 5번 연속 터치 → PIN 입력(초기값 0000) →
  모드 강제 고정(게임/안내/자동), 시간표 확인, 현재 시각, 버전, 화면 테스트 패턴, 캐시 새로고침.
  PIN 은 config 에 두되 교내 공용 기기라 보안 수준이 낮다는 점을 문서에 적어라.
- 아무도 만지지 않으면(게임 90초, 안내 45초) 대기 화면으로 복귀.

# 7. 🎮 서라벌 탐방 게임 모드
## 7-1. 게임 규칙 (짧고 단순하게)
- 제목 예: "서라벌 탐방 스탬프 랠리"
- 시작: 아바타 4~6종(기존 avatars.png) 중 터치로 선택(이름 입력 없음) → 교정의 중앙현관 앞(새 school.png 앞)에서 출발.
  스탬프·결과 카드 그림도 school_art.py 팔레트로 그린다.
- 미션: 무작위로 뽑힌 장소 3곳을 찾아가 스탬프 받기(제한 시간 3분). 장소는 rooms.json 의 game:true 실 중에서
  층·구역이 고르게 섞이게 뽑는다. 각 장소에 도착하면 NPC(선생님·친구)가 학교 관련 OX 퀴즈 1문제
  (kiosk/data/quiz.json, 교사가 수정 가능). 맞히면 스탬프 + 보너스 시간.
- 끝: 결과 카드(찾은 장소, 걸린 시간, 칭호 예: "중앙계단 마스터", "4층 탐험가"). 개인 정보·랭킹 이름 없음.
  오늘 플레이 횟수·최고 기록만 기기 localStorage 에 익명으로 저장(관리자 메뉴에서 초기화).
- 쉬는시간 10분 안에 여러 명이 돌아가며 할 수 있게 한 판 3~4분 이내.
## 7-2. 조작
- 탭-이동: 맵의 가고 싶은 곳을 터치하면 캐릭터가 길찾기로 걸어감(가장 중요, 기본 조작).
- 보조: 화면 왼쪽 아래 큰 방향 패드. 계단·EV 앞에서 터치하면 층 선택 팝업(1~4층).
- 화면 위 미니맵은 ┌자 모양, 현재 위치·다음 목표 화살표 표시. "길 안내" 토글로 목표까지 발자국 표시.
## 7-3. 맵
- 01번 작업으로 만든 ┌자 교정(school.json, 새 school.png)·floor1~4 맵을 그대로 쓴다. 실 내부는 기존 room 맵을 재사용하되,
  게임 모드에서는 실 안으로 들어가지 않고 '문 앞 도착'으로 스탬프를 처리해 짧게 유지한다(설정으로 변경 가능).
- 기존 게임의 생애설계 스토리·퀴즈·다이어리·Sheets 저장 기능은 키오스크 모드에서 모두 끈다.
