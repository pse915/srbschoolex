# 03. 서라벌 학교 탐방 게임 새로 만들기 + 학교 전체 지도 — Claude Code 프롬프트

지금 게임(srbschoolex)은 생애설계 학습 게임의 뼈대를 그대로 쓰고 있습니다.
스토리 라인, 퀘스트·퀴즈, 다이어리, 노란 길 안내 화살표·발자국, 미래 마을이 남아 있습니다.
이 프롬프트는 **그림과 학교 배치 데이터만 가져와** 학교를 둘러보는 **새 게임**을 만들고, **학교 전체 지도** 화면을 추가합니다.
기존 게임은 지우지 않고 그대로 둡니다.

## 02 프롬프트와의 관계
- 03을 02보다 **먼저** 진행합니다.
- 02(사이니지)의 "탐방 게임 모드"와 "위치 안내 화면"은 03에서 만든 게임과 지도 모듈을 다시 쓰면 됩니다.

# 4) 새 게임 설계: "서라벌 탐방"
- 시작: 대기 화면(school-hero.png) → 아바타 6종 중 하나를 터치로 고름(이름 입력 없음) → 교정 중앙현관 앞에서 출발.
- 맵: 교정(school) → 중앙현관 → 1~4층 ┌자 복도 → 각 실(room-*). 계단·EV에서는 층 선택 팝업을 띄운다.
- 핵심 놀이 — 장소 도감과 탐방 카드:
  - 각 실·교정 장소에 처음 들어가거나 문 앞에 닿으면 "장소 카드"를 얻는다.
    - 카드 내용: 이름, 층, 구역(본관/서쪽 동/교정), 카테고리 색, 한 줄 소개
  - 소개 문장은 school_layout.json 의 description 을 쓴다. 비어 있으면 카테고리별 기본 문장을 쓴다.
    학교 정보(교훈·연혁·교사 실명 등)는 지어내지 않는다.
  - 도감 화면에서 층별·카테고리별 수집률을 본다. game:false 인 곳(교직원화장실·탈의실 등)과 confirmed:false 인 곳은 카드에서 뺀다.
- 미션(선택해서 하는 짧은 놀이):
  - "찾아가기": 장소 이름만 보여 주고, 지도를 직접 보고 찾아가게 한다. 화살표 없음, 층과 이름만 제시.
    3곳을 찾으면 스탬프와 결과 카드(걸린 시간, 칭호 예: "서쪽 동 탐험가", "4층 마스터")를 준다.
  - 제한 시간 3분은 켜고 끌 수 있다.
  - 장소는 층·구역이 고르게 섞이도록 뽑는다.
- 사람들: 복도와 교정에 안내 학생·선생님 NPC(npcs.png)를 몇 명 둔다.
  - 말을 걸면 근처 장소를 알려 주는 한두 문장만 한다. 예: "이 복도 끝에 과학실1이 있어"
  - 문장은 places.json 에서 자동으로 만든다(가장 가까운 실, 계단 방향)
- 저장: 기기 localStorage 에만 익명으로 저장한다. 서버 저장 없음.
  - 저장 내용: 도감, 최고 기록, 고른 아바타
  - 설정 화면에서 기록 지우기
- 조작:
  - 탭-이동: 가고 싶은 칸을 누르면 그곳까지 걸어간다. 이동일 뿐 길 안내 표시는 하지 않는다
  - 화면 왼쪽 아래 방향 패드
  - 키보드: 방향키/WASD, Enter=말 걸기·들어가기, M=지도
  - 여러 손가락이 동시에 닿으면 첫 터치만 쓴다
- 화면 위에 작은 미니맵(┌자)을 둔다. 내 위치만 표시하고 목표 화살표는 표시하지 않는다.

# 5) 학교 전체 지도 (게임 안 [지도] 버튼 + 단독 화면 ?map)
- 탭: [교정] [1층] [2층] [3층] [4층] [입체]
  - 교정: school-ground + school + 목련관·정문·후문·급수대 그림을 school-footprint.json 좌표로 한 화면에 맞춰 그린다. 정수 배율
  - 층: floor-plan-N@3x.png 위에 실 이름을 HTML 글자로 얹는다(그림에는 글자를 굽지 않는다)
    - 좌표는 kiosk-plan.json 의 polygon 중심을 쓴다
    - 좁은 실은 글자를 줄이거나 번호 + 목록으로 대신한다
  - 입체: render_stack() 그림. 고른 층만 진하게, 나머지는 반투명
- 범례: 카테고리 색(교실·교무/행정·특별실·학생지원·화장실·계단·EV)
- 검색: 이름·별칭(aliases)으로 찾는다. 예: "위클래스" → Wee클래스, "도서관" → 글빛도서관
  - 결과를 누르면 해당 층 탭으로 바뀌고 그 실이 깜빡인다
- 장소 정보 칸: 누른 실의 이름, 층, 구역, 안쪽/바깥쪽, 양옆 실, 가장 가까운 계단·EV
- "지금 여기" 핀:
  - 게임에서 열면 플레이어 위치
  - 단독 화면(?map)에서는 kiosk-plan.json 의 kiosk 위치(1층 중앙현관)
- "현관에서 가는 길" 보기는 지도 화면 안에서만 켜는 선택 기능이다.
  - kiosk-plan 그래프로 계산한 점선과 단계 문장을 보여 준다
  - 게임 화면에는 길 안내를 띄우지 않는다
- confirmed:false 구역(4층 서쪽 끝)은 회색 빗금 + "확인 필요"로 표시한다. 지어내지 않는다.

# 6) 디자인
- 학교 그림은 school_art.py 그림체를 쓴다. UI는 크림색 바탕에 school_art 팔레트(BRICK, CANOPY, VAULT_C, HEDGE 등)를 강조색으로 쓴다.
- 한국어 기본. 글자는 크게, 터치 대상은 1080p 기준 64px 이상(사이니지에서는 96px).
- 1280×720, 1920×1080, 태블릿 세로(820×1180)에서 깨지지 않게 한다.
- 소리는 기본 꺼짐.
