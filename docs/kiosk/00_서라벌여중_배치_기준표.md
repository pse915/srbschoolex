# 서라벌여자중학교 공간 배치 기준표 (교실배치도 기반)

> 이 문서는 아래 두 프롬프트(01 외관 픽셀아트, 02 사이니지 웹앱)가 공통으로 따르는 **공간 사실 기준**입니다.
> 저장소에 `docs/kiosk/00_서라벌여중_배치_기준표.md`로 넣어 두고 Claude Code에 "이 문서를 기준으로" 라고 지시하세요.
> 실 이름은 교사가 확인한 값입니다. 01번 작업 뒤에는 이 표가 `data/school_layout.json`으로 옮겨지며, 이후 수정은 그 파일에서 합니다.
> 학교 외관 그림체는 `tools/school_art.py`(코드 픽셀아트)가 기준입니다(아래 4장).

## 1. 건물 전체 모양: ┌ 자

교실배치도는 건물을 **한 줄로 펼쳐서** 그린 것입니다. 실제로는
**1층 기준 `학습지원실2`와 `행정자료실` 사이 계단(꺾임 계단)** 을 경계로,
그보다 서쪽(배치도 왼쪽) 부분 — 행정자료실·화장실부터 끝까지 — 이 **1~4층 모두 90° 꺾여 남쪽으로 뻗어** 운동장을 감쌉니다.

```
                      북 (후문)
   ┏━━━━━━┳━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
   ┃ 꺾임 ┃   본관 동서동                                  ┃ → 동쪽 끝(과학실1 / 가정실 / Wee클래스 / 글빛도서관)
   ┃ 계단 ┃   북쪽: EV·중앙계단·교직원화장실 등 지원공간       ┃
   ┃      ┃   가운데: 복도                                  ┃
   ┃      ┃   남쪽: 교실 (운동장을 바라봄)    [중앙현관]▼     ┃
   ┣━━━━━━┻━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛
   ┃ 서쪽 ┃                                                      ● 정문 (동쪽)
   ┃ 남북 ┃                    운 동 장
   ┃  동  ┃   (바깥=서쪽: 화장실 등 / 가운데: 복도 / 안쪽=동쪽: 교실, 운동장을 바라봄)
   ┃      ┃                                          ┏━━━━━━━━━━┓
   ┃ 남쪽 ┃                                          ┃ 목련관     ┃ 1층 식생활관·조리실
   ┃  끝  ┃                                          ┃ (별동)     ┃ 2층 목련관(강당)
   ┗━━━━━━┛                                          ┗━━━━━━━━━━┛
                      남
```

- **중앙현관은 본관의 남쪽(운동장 쪽) 면**에 있고, 바로 안쪽 북쪽에 **중앙계단**이 있습니다.
- **엘리베이터(EV)** 는 중앙계단보다 서쪽, 꺾임부 가까이 있습니다(각 층 동일 위치).
- 각 층 화장실: 꺾임부 바깥쪽(서쪽 동 쪽) 1곳 + 본관 동쪽 끝 1곳 + 교직원화장실(중앙계단 옆).
- 외부: 운동장(건물 안쪽 모서리), 급수대(운동장 북서쪽), 정문(동쪽), 후문(북쪽), 목련관(남동쪽 별동), 화단·보도블럭(건물 남쪽면 따라), 건물 서편 양궁장·분리수거장.
- 사이니지(플립2) 설치 위치: **1층 중앙현관**, 중앙계단 쪽에 놓임.
  화면을 보고 선 사람은 **북쪽(중앙계단)을 바라봄** → 사람 기준 **왼쪽 = 서쪽**(EV·꺾임부·서쪽 동), **오른쪽 = 동쪽**(방송실·과학실 방향), **등 뒤 = 중앙현관 출입문·운동장**. 중앙계단은 사이니지 바로 뒤쪽.

> 방위(동서남북)는 배치도 기준입니다(정문=오른쪽=동쪽). 운동장 사진으로 ┌자 구조가 확인되었습니다(아래 1-1).

## 1-1. 운동장 사진으로 확인한 외관 특징
사진은 운동장 안쪽에서 꺾임 모서리 쪽(서쪽)을 바라본 모습입니다.
- **오른쪽 앞에서 뒤로 길게 뻗은 동 = 본관**. 4층, 붉은 벽돌, 흰 창틀 2연창, 창 묶음 사이 세로 벽돌 기둥(약간 돌출), 평지붕.
- **중앙현관**: 본관 운동장 쪽 면. 짙은 회색 띠 모양 캐노피(현수막 걸림) + 흰 원기둥 2개, 앞에 몇 단 계단.
  바로 옆(운동장 쪽)에 **화강석 조회대**(계단 + 스테인리스 난간)가 붙어 있음.
- **뒤쪽 모서리에서 왼쪽으로 뻗은 동 = 서쪽 동**. 4층, 본관과 같은 외장. 모서리에 옥상 위로 조금 더 높은 **계단탑**.
- **서쪽 동 남쪽 끝 구역**: 중간 계단·출입구(움푹 들어간 세로 줄)를 지나면 **아치형(반원) 파란 금속 지붕**을 얹은 부분이 있고 외벽에 학교 이름 간판이 있음.
  층수가 본관보다 낮아 보임 → 배치도의 **4층 서쪽 끝 "미표기" 구역은 이 아치 지붕(4층 없음)으로 추정**. 교사 확인 필요.
- 건물 앞을 따라 화단·조경수(소나무), 서쪽 동 1층에 작은 캐노피 출입구.
- **시계탑·유리 커튼월 없음** (기존 게임 그림에만 있음 → 새 그림에서 뺍니다).

## 3. 기존 3-3game과 다른 점 (수정 필요)
- `build_world.py`의 `floors` 목록은 "실제 배치도 확인 전 임시 구성"이며, 위 표와 이름·순서가 다릅니다(예: `국어 관련 교과 공간`·`국어도서관` → 실제 `글빛소회의실`·`글빛도서관`, 교실 1-1~3-6 위치 등).
- 층 맵 `floor1~4.json`은 일자 복도 구조 → **꺾임부에서 90° 꺾이는 ┌자 복도**로 바꿔야 합니다.
- 외관 `assets/school.png`는 날개동이 **뒤쪽(북쪽)** 으로 뻗은 모양 → 실제는 날개동이 **앞쪽(운동장/남쪽)** 으로 뻗어 운동장을 감싸고, 중앙현관이 운동장을 바라봅니다.
- 기존 외관의 시계탑·유리 커튼월·유리 캐노피 → 실제는 짙은 회색 캐노피 + 흰 기둥 현관과 조회대(1-1 참고).
- 서쪽 동 남쪽 끝은 아치형 지붕 구역(1-1 참고).
